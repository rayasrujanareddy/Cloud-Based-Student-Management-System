# Cloud-Based Student Management System

A full-stack Student Management System built using React.js, Python Flask, and PostgreSQL. The application allows users to manage student records through a simple web interface.

## Technologies Used

- **Frontend:** React.js, JavaScript, CSS
- **Backend:** Python, Flask, REST API
- **Database:** PostgreSQL
- **HTTP Client:** Axios
- **Version Control:** Git and GitHub
- **Cloud:** AWS (deployment planned)

## Features

- Add new student records
- View all student records
- Edit existing student details
- Delete student records
- Store student information in PostgreSQL
- Connect frontend and backend through REST APIs

## Local Setup

### 1. Clone the Repository

```bash
git clone https://github.com/rayasrujanareddy/Cloud-Based-Student-Management-System.git
cd Cloud-Based-Student-Management-System
```

### 2. Backend Setup

Navigate to the backend folder:

```bash
cd backend
```

Create a Python virtual environment:

```bash
python -m venv venv
```

Activate the virtual environment on Windows:

```powershell
.\venv\Scripts\Activate.ps1
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

### 3. PostgreSQL Database Setup

Create a PostgreSQL database named `student_management`.

```sql
CREATE DATABASE student_management;
```

Connect to the `student_management` database using pgAdmin or PostgreSQL Query Tool and execute the following SQL statement to create the students table:

```sql
CREATE TABLE IF NOT EXISTS public.students
(
    id INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    email VARCHAR(150) NOT NULL UNIQUE,
    course VARCHAR(100) NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

### 4. Backend Environment Configuration

Create a `.env` file inside the `backend` folder with your PostgreSQL connection settings:

```env
DB_HOST=localhost
DB_PORT=5432
DB_NAME=student_management
DB_USER=your_database_user
DB_PASSWORD=your_database_password
```

Replace the database username and password with your actual PostgreSQL credentials.

Start the Flask backend:

```bash
python app.py
```

Backend runs at:

`http://127.0.0.1:5000`

### 5. Frontend Setup

Open another terminal and navigate to the frontend folder:

```bash
cd frontend
```

Install the frontend dependencies:

```bash
npm install
```

Start the React development server:

```bash
npm run dev
```

Frontend runs at:

`http://localhost:5173`
